## 🚀 Was kann das Ding?

📊 **Hardware-Monitor**
Live-Werte für CPU- und GPU-Temperatur, RAM,
Spannungen, Lüfter, VRAM und Hotspot,
mit Farbwarnungen, damit du sofort siehst,
wenn's heiß wird. 🌡️🔥

🎮 **Game-Logger**
Zeichnet beim Zocken die Hardware-Werte auf
(Min / Max / Durchschnitt), damit du nach
der Session genau weißt, was dein PC geleistet hat. 🕹️

🧹 **Cleaner & SSD-Check**
Sicheres Aufräumen für Windows 11 und
NVMe-SMART-Gesundheitswerte für deine SSD. 💽

🌐 **Netzwerk-Scanner**
Schneller LAN-Scan mit 40 Threads (ARP/MAC),
damit du siehst, wer in deinem Netz unterwegs ist. 📡

🩺 **Absturz-Analyse**
Hilft bei der Suche nach der Ursache, wenn
Windows mal wieder zickt (WER). 🔍

🔥 **Throttling-Erkennung & Temp-Log**
Erkennt Leistungsdrosselung durch Hitze und
speichert Min/Max/Durchschnitt deiner Temperaturen. 📈

## 🇬🇧 English in short

**MB-NEXUS Cockpit** is a free Windows 10/11
hardware monitor and system cleaner with
CPU/GPU temperature logging, game session
logging, NVMe SMART health, a LAN scanner and
a crash analyzer. No ads, no tracking.
The UI is currently German only.
More info: [English page](https://mb-nexus-cockpit.sourceforge.io/index-en.html)
